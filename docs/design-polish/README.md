# Визуальная полировка · PR №1: чемпионат и центры матчей

Ветка `feature/design-polish-matches`, база `04a9e4d` — main после объединения PR #33. [Исходный аудит](audit.md) выполнен до изменений. PR предназначен для отдельной проверки, автоматического объединения и production-публикации нет. PR №2 не начат.

## Изменённые экраны

- Чемпионат: компактные строки календаря, переключатель разделов, навигация тура и видимые фильтры команды/статуса. Таблица и бомбардиры сохраняют данные, порядок и функции; меняется общий переключатель разделов.
- Общие центры матчей: одно табло с турниром, статусом, эмблемами, счётом/прочерком, датой и местом. Повторная карточка сведений убрана. Авторы голов, хронология, составы, карточки и замены используют прежние подтверждённые сведения. Официальный протокол остаётся доступен.
- Запланированный УОР — «Судак»: один статус и один экземпляр даты/стадиона; без событий и составов. Ограничение неполноты видно сразу, время подтверждения доступно в «Данные РФФК».

Старые 16 протоколов «Судака» сохраняют прежнюю разметку и стили. Проверка по официальному ID защищает и их общие URL-алиасы. Клубы, составы и профили не перерабатываются в этом PR.

Матчи измерены на 18-м туре без фильтров, от начала страницы до фиксированного нижнего меню. Для 320/390/768/1440 при одинаковой высоте 844 px результат — четыре полные строки вместо двух. Высота строки уменьшилась на **44%**, плотность выросла вдвое. Высота не фиксируется: при длинном названии и увеличенном тексте строка растёт. После применения фильтра остаётся одна подходящая игра — это не снижение плотности.

Авторы голов завершённого матча теперь видны на первом экране. Неизвестная дата явно обозначена; год, опубликованное время и исходные статусы сохранены. Длинные названия переносятся без многоточия, эмблемы используют contain. Переход по всей площади строки и две отдельные ссылки клубов доступны без вложенных ссылок; дублирующих шеврона и подписи «Центр матча →» нет.

## Типографика и области нажатия

Локальная шкала отступов — 4/8/12/16 px, разделы центра — 20 px. Счёт календаря — 26 px, названия — 14 px, метаданные — 12 px. Табло — 36–56 px, заголовки разделов — 16 px, второстепенные сведения — 12–13 px. Эмблемы — 24×24 px в списке и 48×48 px в табло. Используются прежние токены обеих тем; новых цветов, градиентов, шрифтов или UI-зависимостей нет.

Клубные ссылки календаря, переходы к центру, табы, стрелки и select имеют области не меньше **44×44 CSS px**. Весь матч открывается также при нажатии на дату; Enter открывает тот же центр. Фокус выделяет всю строку. Прежние safe-area и нижнее меню сохранены. Проверены переносы и 150% текста на 320 px в обеих темах. Новые стили ограничены `#table` и opt-in `.match-polish` внутри `#match`; CSS главной не меняется. Встроенные стили синхронизированы с двумя существующими CSS-файлами, дополнительных запросов для офлайн нет.

## Проверки

- Python: **136/136**, `python -m unittest discover -s tests -v`.
- Node: **97/97**, `node --test tests/*.test.cjs`.
- Браузер: **17/17** — прежние 15 entrypoints и два новых сценария аудита/визуального сохранения. Сводка итогового прогона — [test-results.json](test-results.json); удалённый прогон виден в Checks PR.
- Все 11 клубов, 100 известных матчей и 113 исходных записей календаря; завершённые/запланированные/технические/перенесённые, неполные протоколы, отсутствующие даты, длинные названия и отказ эмблем. Общий матчевый сценарий расширен до 1440 px и повторно открывает все 100 центров офлайн.
- Все фильтры, прямые ссылки, перезагрузка, Back/Forward, возврат с сохранением тура, фильтра, прокрутки и фокуса; ссылки клубов сохраняют самостоятельное действие.
- Обе темы, 320/390/768/1440 px, reduced motion; горизонтального переполнения и ошибок JS нет. Девять контрольных экранов сняты в каждой комбинации. Недоступные внешние фотографии проверяются предусмотренными инициалами; сами ресурсы/URL сохранены.
- Реальный SW, сохранённый снимок, офлайн-перезагрузка календаря, центров, составов и профилей; клубные эмблемы, 16 прежних протоколов и 41 профиль доступны. Проверены возврат сети, устаревший CDN, HTTP 503 и обновление без перезагрузки. Дополнительно проверен свежесобранный review-сайт через `PAGES_SITE_ROOT`, без deployment.

`design-preservation.browser.cjs` сравнил **160 пар** реальных PNG и полного представления DOM с HTML main: главная, Каштан, его состав, Никита Попов и все 16 прежних центров × четыре ширины × две темы. Текст, геометрия и стили совпали. **Восемь PNG главной совпали побайтово**, в том числе независимо снятые кадры исходного аудита. [Результаты](preservation.json).

У остальных сравнений максимальное отличие — 26 пикселей; вне края существующей кнопки нижней навигации дельта не больше двух уровней RGB. Нативный Chromium иногда иначе квантует сглаживание скруглённого края прежнего градиента меню: тест допускает только полосу 1,25 px вокруг активной кнопки, максимум 100 пикселей и 40 уровней RGB. Фактически максимум — 14 таких пикселей. Остальной растр сохраняет прежний допуск ≤2 RGB в ≤0,1% пикселей. Стили меню не менялись. Прежний независимый `multi-club.browser.cjs` также прошёл сравнение четырёх вкладок без расширения его допуска.

CI добавляет только два теста и артефакты сравнения. Workflow публикации и настройки Pages не меняются. Запуск через системный launcher и физическая системная кнопка Android Back отдельно не автоматизировались; браузерная история и настоящий офлайн проверены Chromium в Termux.

## Данные и оставшиеся UX-задачи

[58 защищённых файлов](protected-files.json) побайтово совпадают с базой: `data.json`, парсеры и скрипты, источники/ID, фотографии и эмблемы, `modern-home.css`, `sw.js`, manifest, PWA-иконки и production-workflow. Футбольные результаты, показатели, формат, сопоставления и алгоритмы не менялись. Новых доказанных проблем данных в дизайнерском PR не исправлялось. Ранее зафиксированные ограничения шести частичных протоколов, неизвестные даты/время и 13 записей с неподтверждёнными участниками сохраняются; UI не заполняет их догадками.

Для отдельно подтверждаемого PR №2 остаются: длина клубной страницы до состава, равнозначные блоки командных/индивидуальных показателей, повторяющиеся подтверждения источника, технические даты регистраций и представление матчей игрока. Сам клубный список уже имеет строки 44 px — дальнейшая плотность должна достигаться композицией, а не уменьшением нажатий. Этот PR не начинает переработку клубов или профилей.

## Воспроизведение

```sh
python -m unittest discover -s tests -v
node --test tests/*.test.cjs
DESIGN_PHASE=before node tests/design-polish.browser.cjs # только на исходной базе
node tests/design-polish.browser.cjs
MULTI_CLUB_BASELINE_HTML=/path/to/base-index.html node tests/design-preservation.browser.cjs
```

Остальные браузерные команды перечислены в CI. `PLAYWRIGHT_MODULE` и `CHROMIUM_EXECUTABLE_PATH` позволяют использовать имеющийся локальный renderer; в Termux также применён уже настроенный адаптер Node platform. Новые пакеты не устанавливались. В CI HTML для сравнения берётся из base SHA PR, а не из текущего кандидата.
