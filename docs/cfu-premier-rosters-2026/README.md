# Премьер-лига КФС, сезон 2026: составы клубов

Статус: **этап 2, независимые составы и профили футболистов**. Матч-центры,
протоколы и статистика матчей в этот этап не входят.

Официальный источник: [Чемпионат Премьер-лиги КФС](https://www.cfu2015.com/matches/premier-leagueCFU/).
Страницы клубов: `https://www.cfu2015.com/teams/<slug>/`.
Профили футболистов: `https://www.cfu2015.com/players/<id>/`.

## Структура снимка

`rosters.json` и его точная публикуемая копия `cfu-premier-rosters-2026.json`:

- `schemaVersion: 1`, `provider: "cfu"`, `competitionKey: "cfu-premier-2026"`, `season: 2026`;
- `playersById` — официальный ID `cfu:player:<id>`, URL профиля, опубликованное имя и дата рождения;
- `rostersByTeamId` — семь клубов, для каждого: URL, время проверки, статус, полнота, SHA-256 исходной страницы и записи сезона;
- запись сезона: `playerId`, `position`, `positionGroup`, `shirtNumber`, `registeredAt`, `deregisteredAt`, при наличии — `registrationNote` (например, «аренда»);
- `sourceMetadata` — источник, robots, crawl-delay, способ получения и сводные счётчики;
- `unresolvedRecords` — записи, которые не удалось подтвердить. В текущем снимке пусто.

Идентификатор футболиста никогда не строится из фамилии. Клубная принадлежность,
номер и отзаявка — свойства сезонной записи, а не личности. Снимок не содержит
идентификаторов или клубов РФФК.

## Импорт и тесты

```powershell
python -m scripts.cfu_premier_rosters `
  --output docs/cfu-premier-rosters-2026/rosters.json `
  --public-output cfu-premier-rosters-2026.json

python -m unittest discover -s tests -p "test_cfu_premier_rosters.py" -v
node --test tests/cfu-premier-rosters.test.cjs
```

Для офлайн-повтора: `--html-dir <каталог>` с файлами `<slug>.html` или
`team-<slug>.html`. Импорт атомарный: при ошибке сети, обрезанной странице или
неполном составе предыдущий полный снимок не заменяется. При падении источника
клиент сохраняет последний проверенный снимок в отдельном ключе
`sudak-cfu-premier-rosters-v1`.

## Интерфейс

На странице клуба КФС появился раздел «Состав · сезон 2026» с группами позиций,
номером, именем, позицией и отметкой «Отзаявлен». Указаны дата проверки и ссылка
на официальную страницу клуба. Нажатие открывает внутренний профиль
`#player=cfu:player:<id>&team=cfu:team:<slug>&from=team`.

Профиль показывает ФИО, клуб сезона, позицию, номер, дату рождения, отметку об
отзаявке и ссылку «Профиль на сайте КФС». Статистика матчей и голов не
показывается, пока она не импортирована и не подтверждена. Переходы из состава,
кнопка «Назад», браузерный Back, прямая ссылка, reload и сохранённый офлайн-снимок
поддерживаются. Игроки КФС не смешиваются с игроками РФФК.
