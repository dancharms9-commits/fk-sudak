# Запуск установленного PWA на Android

PR #12 добавил одну веб-заставку на 3500 мс. Другой экран с маленькой эмблемой
не создаётся HTML/JavaScript: его показывает Android/Chrome до первого кадра
установленного приложения, используя manifest. Эмблема в шапке принадлежит
основному интерфейсу и закрыта веб-заставкой во время запуска.

До исправления фон manifest и theme-color был `#0F2C45`, а фон веб-заставки
и установочных иконок — `#001329`. Переход дополнительно подчёркивали разные
цвета и смещение большой эмблемы вверх из-за нижней строки названия.

Теперь manifest background_color/theme_color, HTML theme-color, ранний фон
HTML и веб-заставка используют `#001329`. Временный фон HTML снимается
при закрытии заставки, сохраняя прежнее оформление самого приложения.
Большая эмблема центрирована в доступной области с учётом safe-area;
название закреплено отдельно внизу.
Ширина эмблемы по-прежнему 70vw (максимум 380px), на низких экранах она
пропорционально вписывается по высоте. Исходный PNG, иконки 192/512 и отдельная
maskable-иконка с безопасными полями не изменены.

Веб-заставка сохраняет появление 0–0,5 с, исчезновение 3,0–3,5 с и статичный
показ все 3500 мс при prefers-reduced-motion. Логика показа, навигация,
данные и офлайн-логика сохранены; версия оболочки SW — sudak-launch-v6.

## Ограничения и проверка на телефоне

Android задаёт размер, маску, положение и длительность системной иконки.
Веб-код не может отключить системный экран или надёжно сделать его эмблему
размером 70vw. Общий фон и центрирование смягчают переход, но полного
совпадения двух изображений на всех устройствах гарантировать нельзя.
Не используются вымышленные manifest-поля, нативные API или масштабирование
иконок за пределы безопасной области.

Ранее установленный WebAPK может получить новый цвет manifest позже, чем
обновится веб-страница: этим обновлением управляет Chrome. Имя, адрес manifest,
start_url, scope и display сохранены, поэтому идентичность приложения не меняется.

На устройстве после применения обновлённого manifest следует проверить новый
и повторный запуск из значка, одинаковый фон системного и веб-экрана, отсутствие
промежуточного кадра шапки/старой эмблемы/белого фона, затем запуск без сети и
системную настройку уменьшения анимации. Браузерные тесты проверяют веб-часть,
настоящий SW и manifest; запуск Android WebAPK ими не эмулируется.
