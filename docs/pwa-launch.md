# Запуск установленного PWA на Android

## Финальная эмблема

Используется предоставленный владельцем PNG `assets/club-crest-final-original.png`,
1086×1448 (3:4), сохранённый побайтно, без перерисовки, перекраски и обрезки.
SHA-256: `c8ed5b87dbf6a9c17fcbcc61974a9f4bd06418b3ef60ac8dddb534a6a504513b`.
Предыдущий исходник `assets/club-crest-original.png` не изменён. Предыдущие
установочные PNG сохранены в `assets/previous-crest/crest-v4/`; более ранний
архив `assets/previous-crest/` также сохранён.

`node scripts/generate-club-crest.cjs` воспроизводит иконки через существующий
Playwright/Chromium, без новых зависимостей. Полное изображение пропорционально
вписывается в непрозрачный квадрат с фоном `#001329`. Собственный фон внутри
PNG сохраняется: перекрашивается только окружающий холст, не изображение:

- `icon-192.png` и `icon-512.png` (`purpose: any`) — 94% высоты холста.
- `icon-maskable-512.png` — 63% высоты. При пропорции 3:4 даже углы полного
  изображения находятся внутри безопасного круга радиуса 40% стороны
  (радиус до угла около 39,4%). Защитные поля сохраняют оба мяча и весь щит.
- `favicon.png` — 32×32, `apple-touch-icon.png` — 180×180, также с полями 3%.
- `fk-sudak-pwa-*.png` — побайтные копии соответствующих установочных иконок,
  чтобы служебный `apply_visual_refresh.py` не восстановил старую эмблему.

Адреса иконок имеют версию `final-crest-v7`. Новый исходник имеет отдельное имя:
старый SW не сможет вернуть предыдущий PNG из своего cache-first обработчика.
SW `sudak-launch-v7` заранее кэширует новый оригинал, manifest, HTML и все пять
иконок; после установки удаляет предыдущие кэши оболочки, включая v6.
Стратегии запросов и обход SW для data.json сохранены. Данные и статистика,
локальное сохранение, навигация и почасовое обновление не изменялись.

## Один непрерывный запуск

Android/Chrome показывает системный экран до первого веб-кадра установленного
PWA, используя manifest. Затем HTML показывает единственный веб-оверлей;
маленькая эмблема шапки закрыта им до завершения запуска.

Manifest background_color/theme_color, HTML theme-color, ранний фон HTML,
веб-заставка и фон иконок согласованы: `#001329` в обеих темах. Цвет системных
панелей задаётся через theme-color в пределах поддержки Android/Chrome.
Временный фон HTML снимается после запуска, сохраняя оформление приложения.

Эмблема центрирована в доступной области с учётом safe-area; подпись закреплена
отдельно внизу. Ширина 70vw (максимум 380px), на низких экранах изображение
вписывается по высоте без обрезки. Установочная maskable-иконка и веб-экран
содержат одну и ту же полную эмблему.

Убрано повторное появление эмблемы из прозрачности: после её загрузки веб-эмблема
сразу непрозрачна. Исчезновение остаётся плавным в интервале 3,0–3,5 секунды.
Веб-интервал 3500 мс отсчитывается после готовности изображения и интерфейса;
при reduced motion эмблема статична все 3500 мс. Контроллер создаётся один раз
на документ. Переходы между разделами, возврат к вкладке, focus, visibilitychange
и обновление данных не запускают заставку повторно. Новая загрузка документа
(включая перезагрузку) запускает её снова. Прежние обработка ошибок и ограничение
ожидания запуска 8 сек. сохранены.

Android определяет размер, маску, положение и длительность системной заставки.
CSS/JavaScript обычного PWA не могут отключить её, управлять её длительностью
или гарантировать совпадение размера с большой веб-эмблемой. Общие цвета,
центрирование и отсутствие повторного fade-in смягчают переход. Изменять рисунок
или выходить за maskable safe zone ради увеличения системной иконки нельзя.

## Обновление установленного приложения

После объединения PR и публикации GitHub Pages:

1. Открыть PWA с интернетом, дождаться загрузки, затем полностью закрыть его
   и открыть снова: новая оболочка и рисунок должны загрузиться через SW.
2. Проверить шапку, большую заставку, повторный запуск и открытие без сети.
3. Если веб-эмблема новая, а значок Android или системная заставка ещё старые,
   дать Chrome время на отдельное обновление manifest/WebAPK (обычно день-два).
   Название и адрес manifest, start_url, scope и display не менялись.
4. Если Android продолжает использовать старый значок, удалить установленное
   PWA/старый ярлык и установить приложение заново из обновлённого сайта в Chrome.
   Перед удалением полезно открыть сайт онлайн: локальный офлайн-кэш при удалении
   может быть потерян. При новой установке открыть приложение с сетью один раз.

На физическом устройстве нужно оценить системный и веб-экраны, цвета панелей,
отсутствие промежуточного кадра старой эмблемы/шапки, запуск без сети и reduced
motion. Браузерные тесты проверяют веб-часть и настоящий SW, включая обновление
активного v6 до v7 и точные байты всех новых иконок офлайн; они не эмулируют
физический запуск Android WebAPK. Исчезновение системной заставки не заявляется.
