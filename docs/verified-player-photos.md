пропорций и целого лица/головы и привязать к указанному ID без изменения статистики.

## PWA и ограничения

Разрешённых новых файлов нет, поэтому `index.html`, CSS, `sw.js` и `manifest.json`
не изменены. Кэш остаётся `sudak-route-v11`; новых ресурсов для precache нет.
Ссылки этого отчёта не загружаются при запуске приложения.

Существующий SW обрабатывает только свой origin. Внешние фото РФФК в его
precache не входят. Без сети либо при ошибке загрузки карточки показывают инициалы.
HTTP-кэш браузера не даёт гарантии офлайн-доступности таких снимков. Этот PR
**не заявляет гарантированные офлайн-фотографии**. Навигация и данные профилей
работают с ранее сохранёнными данными; офлайн-проверки описаны отдельно.
