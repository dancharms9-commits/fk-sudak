# Премьер-лига КФС, сезон 2026: фундамент данных

Статус: **этап 1, только независимый импорт**. Набор не подключён к PWA,
`data.json`, `build_pages.py`, Service Worker или GitHub Actions.

Официальный источник: [Чемпионат Премьер-лиги Крымского футбольного союза](https://www.cfu2015.com/matches/premier-leagueCFU/).
Название соревнования сохранено как на сайте: **«Чемпионат Премьер-лиги Крымского футбольного союза»**.

## Подтверждённые данные

- **7 участников**: ГФК «Ялта», ФК «Заречное», ФК «МАК», ФК «Океан», ФК «Спарта-КТ», ФК «Таврия», ФК «Феодосия».
- **84 матча** в 4 кругах по 7 туров (28 туров, по 3 матча в туре).
- **75 матчей** имеют опубликованный счёт (туры 1–25). **9 матчей** (туры 26–28) — будущие, без счёта.
- Таблица: 7 строк; 1-е место — «Таврия» (20 игр, 46 очков), 2-е — «Ялта» (21 игра, 46 очков). Места, очки и разница взяты из официальной таблицы, а не пересчитаны.
- Официальный ID и URL есть у всех 84 матчей. Пример подтверждённой страницы: `match_18763` («Ялта» — «Таврия», 0:2, статус «Матч завершен»).
- Города и стадионы сохранены там, где опубликованы. Время матча сохранено как опубликованное локальное время; часовой пояс источник явно не указывает, поэтому `timeZone` оставлен `null`, а не выставлен в `Europe/Moscow` предположительно.

## Что не импортировано

Составы, игроки, фото, протоколы, события, судьи, клубные страницы и массовые статусы матчей. Статус отдельного матча можно проверить через `parse_match_page`, но 84 страницы матчей на этом этапе не скачиваются. Счёт в календаре не превращается в вывод «матч завершён»: `status` остаётся `null`, пока статус не подтверждён отдельно.

## Структура снимка

`snapshot.json`:

- `schemaVersion: 1`, `provider: "cfu"`, `competitionKey: "cfu-premier-2026"`, `season: 2026`;
- `teamsById` — ID вида `cfu:team:<slug>`, официальное название, город, URL, `identityConfidence`;
- `matchesById` — ID вида `cfu:match:<id>`, тур, круг, команды, дата, время, стадион, nullable-счёт, nullable-статус;
- `standings` — официальная таблица и `asOfRound`;
- `sourceMetadata` — отдельные `checkedAt`, `status`, `coverage` и причина для команд, таблицы и календаря; `retrieval` фиксирует способ получения;
- `unresolvedRecords` — записи, которые не удалось связать с официальным реестром (сейчас пусто).

Пространство `cfu:` не пересекается с ID РФФК. Клубы КФС не связываются с клубами РФФК по названию или городу. `sourceMetadata.retrieval` в текущем снимке: `saved_raw_html_via_public_read_only_reader`.

## Воспроизведение и тесты

```powershell
python -m scripts.cfu_premier_import --output docs/cfu-premier-2026/snapshot.json
python -m unittest discover -s tests -p "test_cfu_premier.py" -v
```

Для офлайн-повтора из сохранённых страниц: `--html-dir <каталог>` с файлами
`teams.html`, `table.html`, `calendar.html`. Импорт атомарный: при ошибке сети,
неполной или обрезанной странице предыдущий валидный снимок не заменяется.

`docs/` исключён из `stage_site` в `build_pages.py`, поэтому снимок не публикуется на Pages.
