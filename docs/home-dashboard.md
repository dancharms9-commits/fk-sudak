# Главная ФК «Судак»

Главная использует существующие `TABLE`, `NEXT`, `RES`, `MATCH_DETAILS`, `NEWS`
и `playerRows()`. Новых источников данных или зависимостей нет. Данные, все
41 профиль, изображения, manifest и контроллер заставки не изменены.

## Поведение

- Ближайший матч выбирается по дате сезона 2026, независимо от порядка строк.
  Дата без времени остаётся предстоящей весь день по московскому времени.
  Прошедшие неподтверждённые игры не становятся результатами. Неизвестные даты
  исключаются из выбора. Отсчёта нет: нынешняя модель календаря не содержит время.
- Если будущих игр нет, главным становится последний результат с подтверждённым
  числовым счётом. Второй карточки этого результата нет. Существующий маршрут
  `#match=…` теперь также показывает запланированный матч без выдуманного счёта.
- Место берётся из порядка официальной таблицы, игры/очки — из её строки,
  разница — из опубликованных забитых и пропущенных мячей. Неизвестные значения
  показываются прочерком. Общая дата обновления и существующий статус связи
  находятся под разделами; отдельный приблизительный статус таблицы не вводится.
- Лидеры вычисляются по `league_goals`, `league_games`, `league_minutes`.
  Все разделяющие максимум игроки получают ссылки. Общие `federation_games`
  не участвуют. При нуле лидер не объявляется; неизвестные значения и неполные
  данные обозначаются. Портреты проходят существующую проверку `officialPhoto`;
  ошибка загрузки оставляет инициалы.
- В модели нет отдельной клубной ленты или признака важности. Поэтому показаны
  три последние доступные публикации с честным названием «Новости РФФК» и теми
  же внешними ссылками, что в существующем разделе новостей. Офлайн доступны
  сохранённые заголовки; полные материалы находятся на внешнем сайте.

## Интерфейс и обновление

На смартфонах один столбец, от 768 px — два столбца вторичных блоков. Главный
матч занимает всю ширину. Названия переносятся, нижнее меню и safe-area сохранены.
Шапка компактна, с единственной утверждённой эмблемой. Цвет главного матча и
шапки — `#001329`, акценты золотые. Обе системные темы сохранены.

Главная один раз появляется после существующей заставки (opacity, 200 мс).
При новых данных изменяются только отличающиеся блоки; сохраняется фокус ссылки.
Нажатие имеет переход 180 мс. Повторное переключение вкладок не запускает эффект
появления. `prefers-reduced-motion` отключает эффект и сокращает CSS-переходы.
Постоянных анимаций, таймеров главной и новых запросов данных нет.

Почасовое обновление GitHub и существующий опрос открытой вкладки раз в пять
минут сохранены. Сбой обновления оставляет последние полученные данные с
существующим предупреждением. Восстановление сети запускает штатное обновление.

SW получил cache `sudak-home-v8`, чтобы установить обновлённую HTML-оболочку.
Ресурсы утверждённой эмблемы сохраняют свои имена и содержимое. Старый визуальный
updater принимает v8 и не откатывает его. CSS по-прежнему встроен из
`modern-home.css`, поэтому отдельная загрузка стилей офлайн не требуется.

## Проверки

```sh
python -m unittest discover -s tests -v
node --test tests/*.test.cjs
node tests/browser.cjs
node tests/home-dashboard.browser.cjs
node tests/launch-splash.browser.cjs
git diff --check
```

Для существующего локального Chromium в Termux используются `PLAYWRIGHT_MODULE`,
`CHROMIUM_EXECUTABLE_PATH` и локальный адаптер платформы Node через `--import`.
Эти пути не нужны GitHub Actions: там применяется существующий Linux Playwright.

Новый браузерный набор проверяет 320/390/768/1440 px × обе темы × оба режима
движения; переполнение, переносы, отступ от навигации; реальные значения;
переходы/историю/фокус/прокрутку; глубокие ссылки; обновление открытого матча;
пустой календарь, отсутствие будущих игр, таблицы, новостей и статистики;
ошибку обновления; настоящий SW v7 → v8, офлайн-перезагрузку и восстановление
сети. Снимки сохраняются через `VISUAL_SCREENSHOT_DIR` и в артефакте CI.

Существующие наборы дополнительно проверяют все 41 профиль, 16 протоколов,
фильтры, старые офлайн-данные, байты эмблем и иконок, стартовый интервал 3500 мс,
обновление предыдущего SW v6 и защиту от отката данных. Установка WebAPK и
системная Android-заставка на физическом устройстве этим не проверяются.
