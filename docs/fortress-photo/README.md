# Новая фотография крепости на главной

В `assets/home-fortress.jpg` скопирован выбранный пользователем файл `5.jpg`
без пересжатия и ретуши. Фактические размеры файла — 1600 × 1127 px,
размер — 194 869 байт. SHA-256:
`e3707c8fdd9eda3d2fb69b499a72e229814f456dc80852703858d2562415babb`.

Меняется только фотография и CSS фонового слоя главной, включая его встроенную
копию в `index.html`. На экранах до 640 px фотография занимает 84% высоты шапки;
горизонтальная позиция 70% сохраняет центральные башни и башню на вершине.
На более широких экранах используется `cover`, чтобы фотография заполняла ширину.
В тёмной теме поверх изображения наложен `#001329` с прозрачностью около 14%.
В светлой теме цветного затемнения нет. Верхний градиент заканчивается точным
цветом `--bg` до нижней границы фотографии.

Композиция, эмблема, заголовок, карточки, навигация, переключатель тем, скрипты,
данные, manifest, Service Worker и GitHub Actions сохранены.

## Снимки до и после

Исходное состояние — `main` на коммите `6e27bce`. Обе серии сняты одним локальным
Chromium, при высоте окна 844 px и масштабе 1, после загрузки фотографии, шрифтов
и завершения анимаций. Темы выбраны существующим переключателем. Для одинакового
выбора матча время зафиксировано в браузере на 2026-11-05 10:00 UTC; исходные
данные и код приложения не менялись. Service Worker отключён только в контексте
съёмки, чтобы исключить влияние кэша. Удалённые портреты РФФК блокировались;
локальные изображения загружались штатно.

## Проверки

- `python -m unittest discover -s tests -v` — 65 тестов успешно.
- `node --test tests/*.test.cjs` — 65 тестов успешно.
- `node tests/themes.browser.cjs` — 320/390/768/1440 px × обе темы; пять вкладок,
  профили и протоколы, панели чемпионата, контраст, сохранение темы, офлайн.
- `node tests/home-dashboard.browser.cjs` — главная, переходы и обновление данных,
  обычное и сокращённое движение, отступ от нижнего меню, настоящий SW и офлайн;
  также запускает существующую проверку тем.
- Сравнение геометрии до/после, совпадение встроенного CSS с `modern-home.css`,
  побайтовое совпадение выбранной фотографии и `git diff --check` — успешно.

Для запуска браузерных проверок в этом Termux использовались уже установленный
Playwright через `PLAYWRIGHT_MODULE`, локальный Chromium через
`CHROMIUM_EXECUTABLE_PATH` и адаптер платформы Node через `--import`.
