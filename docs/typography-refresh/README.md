# Typography refresh: IBM Plex Sans

Основа: `main` **4b7812a**. PR [#35](https://github.com/dancharms9-commits/fk-sudak/pull/35)
объединён 10 ноября 2026; рабочее дерево перед началом было чистым.
Ветка: `feature/typography-refresh`. Работа и реальные снимки выполнены на ПК,
Windows, Chromium 130.0.6723.31 / Playwright 1.48.2, 11 ноября 2026.

## 1. Прежний шрифт

`system-ui, -apple-system, "Segoe UI", Roboto, sans-serif`, 16 px / 1.4.
На этом Windows-ПК реально отрисовывался Segoe UI; это проверено через Chromium
`CSS.getPlatformFontsForNode`, а не только по значению CSS. Шрифт зависел от ОС.
Декоративная надпись «СУДАК» — существующая SVG-графика; она не заменялась шрифтом.

## 2. Изменения

IBM Plex Sans применён ко всей оболочке, пяти вкладкам, чемпионату, таблице,
спискам и центрам матчей, всем 11 клубам, составам, старым и универсальным
профилям игроков, новостям и статистике. Встроенный блок `data-typography-refresh`
синхронизирован с [typography.css](../../typography.css), отдельный CSS-запрос для
старта или офлайна не требуется.

Использованы только три прямых начертания: 400 для обычного текста, 600 для
заголовков/названий и 700 для выразительных чисел. Счёт сохранил прежний размер,
получил нормальный трекинг и табличные цифры. Таблицы, голы, минуты, номера и
показатели используют `tabular-nums`. Базовый размер и интерлиньяж сохранены;
заголовки имеют интерлиньяж 1.3, новости — 1.55. Размеры крупных названий и счёта
остаются адаптивными из прежних стилей. Длинные ФИО и названия клубов переносятся.

Для текста 150% подписи навигации могут занимать несколько строк, группа фильтров
чемпионата переносится в одну колонку, кнопки амплуа больше не сжимают свои
подписи. Ссылки источников получили минимум 44×44 px. Это изменения под размер
текста; строки матчей, их сетки, переносы статусов, формат/разметка дат и фоны эмблем
в этом PR не перерабатываются.

Состав и порядок DOM, маршруты и футбольная логика сохранены. Удаление нового
блока CSS восстанавливает исходный HTML **точно**, после нормализации переводов
строк Windows. Фотография крепости, исходная эмблема, SVG-надпись, палитра,
структура главной и пять нижних вкладок сохранены. Высота шапки главной в A/B/C
совпадает на всех четырёх ширинах: 358 / 429 / 540 / 540 px.
[Защищённые файлы и SHA-256](protected-files.json) проверены против `main` с его
правилами checkout: данные, парсеры, фото, эмблемы, PWA-иконки, manifest, три
прежних CSS и workflow публикации не изменены.

## 3. Сравнение A / B / C

Выбран **B — IBM Plex Sans во всём интерфейсе**.
[Интерактивное сравнение](comparison.html) содержит все шесть экранов × четыре
ширины × обе темы. Кадры открываются в исходном размере. При просмотре исходников
через GitHub HTML нужно скачать или открыть через локальный HTTP-сервер.

| Критерий | A · системный стек | B · IBM Plex Sans | C · IBM + Roboto Condensed для счёта и основных показателей |
| --- | --- | --- | --- |
| Кириллица | Segoe UI на этом ПК, зависит от ОС | Единая форма букв, полная русская кириллица | Та же кириллица IBM |
| Счёт | Сильный акцент 750/800, близок по жирности к заголовкам | 700, заметно крупнее подписей, аккуратные табличные цифры | Цифры уже, но практической прибавки к читаемости нет |
| Плотность | Исходная | Основная композиция сохранена | В контрольных кадрах не добавляет целую видимую строку |
| Длинные названия | Штатные переносы | Нет обрезанных названий/ФИО, высота растёт с текстом | Названия набраны тем же IBM, выигрыша нет |
| 320 px | Исходные кадры | Без горизонтальной прокрутки, проверено также 150% текста | Числа компактнее; переносы названий практически те же |
| Согласованность | Одна системная семья, разный вид на ОС | Одна семья для всего интерфейса | Другая форма цифр заметна рядом с текстом |
| Дополнительные WOFF2 | 0 | **193 092 байта** | **214 220 байт**, +21 128 к B |

На 390 px «3:0» в календаре занимает 39.78 px в B и 33.39 px в C; одна цифра
центрального счёта — 22.41 и 18.72 px соответственно. Эта экономия не освобождает
полную строку и не решает переносы длинных команд. Поэтому дополнительная семья
не оправдана. Это визуальная оценка и измерения конкретных кадров, не исследование
предпочтений пользователей. Сырые измерения: [A](A/metrics.json),
[B](B/metrics.json), [C](C/metrics.json).

## 5. Источник, лицензия и размер ресурсов

Официальный пакет IBM `@ibm/plex-sans` **1.1.0**, внутренний font version 3.005;
неизменённые `fonts/complete/woff2/IBMPlexSans-{Regular,SemiBold,Bold}.woff2`.
Подробный [источник и лицензии](../../assets/fonts/README.md),
[исходная OFL 1.1](../../assets/fonts/ibm-plex-sans/OFL.txt), [хэши и покрытие](fonts.json).
В каждом WOFF2 проверены 895 Unicode mappings, в том числе все 66 русских букв,
включая Ё/ё. Ненужные начертания и курсивы не добавлялись.

| Ресурс | Байты |
| --- | ---: |
| Regular 400 | 63 020 |
| SemiBold 600 | 67 060 |
| Bold 700 | 63 012 |
| Всего WOFF2 для приложения | **193 092 ≈ 188.6 KiB** |
| OFL IBM, хранится рядом | 4 456 |
| Roboto Condensed 700, только сравнение C | 21 128 |

WOFF2 локальные, `font-display: swap`, системный fallback. Приложение не
обращается к Google Fonts. CSS встроен в HTML; исходный `typography.css` сам по
себе не запрашивается. SW заранее кэширует все три веса. Roboto хранится только
в `docs/typography-refresh/trial/`; весь `docs` исключён из Pages-артефакта,
поэтому C не добавляет ресурсы в приложение.

## 6. Проверки

Python **136/136**, Node **104/104**. Все **18 существующих браузерных entrypoints**
прошли; после последних правок фильтров повторены затронутые сценарии.
Добавлены три браузерных entrypoints: реальная съёмка, доступность типографики и
обновление шрифтов/офлайн. [Машиночитаемые результаты](test-results.json).

Проверены все 11 клубов, все составы, 368 клубных контекстов игроков × девять
показателей, 41 прежний профиль, прямые ссылки, Back/Forward, восстановление
фокуса/прокрутки, reload, обе темы, четыре ширины и reduced motion. Прежние тесты
проверяют также 100 общих центров, 16 старых протоколов и сбои загрузки данных.

[Текст 150%](accessibility.json): **112 комбинаций** (14 экранов × четыре ширины ×
две темы), включая шапку, навигацию и элементы с исходным размером в px.
Размер каждого элемента умножается один раз от собственного вычисленного размера;
масштаб родителя не умножает повторно уже увеличенный размер ребёнка. Ширина
viewport остаётся прежней. Нет горизонтальной прокрутки, обрезанных элементов
управления, усечённых выбранных подписей select или областей нажатия меньше
44×44 px. Проверены и обычные размеры в прежних браузерных сценариях.

[Сохранение дизайна](preservation.json): **168 пар**, дельта **0 пикселей**,
геометрия/текст/проверяемые стили совпадают. Сюда входят главная, старый профиль,
чемпионат и все старые центры. Эталон мигрирован явно: к HTML исходного `main`
применяется **только** [зафиксированная копия typography.css](../../tests/fixtures/typography-refresh.css).
Тест требует её совпадения с production-блоком. Затем выполняются все прежние
проверки полного DOM и PNG. Численные допуски не расширены, сравнения не отключены,
маски для текста не добавлялись. Аналогично проверены четыре старые вкладки на
старом/новом формате JSON. Исходные кадры A и старые отчёты не перезаписываются.

В CI добавлены новые проверки и сбор артефактов; workflow публикации не менялся.
При создании PR GitHub Actions запускается отдельно: результаты здесь локальные.

Воспроизведение с установленным Playwright 1.48.2 и Chromium:

```sh
python -m unittest discover -s tests -v
node --test tests/*.test.cjs
node scripts/check-typography.cjs
node tests/typography-accessibility.browser.cjs
node tests/typography-offline.browser.cjs
TYPOGRAPHY_PHASE=A node tests/typography-refresh.browser.cjs
TYPOGRAPHY_PHASE=B node tests/typography-refresh.browser.cjs
TYPOGRAPHY_PHASE=C node tests/typography-refresh.browser.cjs
```

Для захвата A задайте `MULTI_CLUB_BASELINE_HTML` с сохранённым HTML исходного
`main`, если локальный `main` уже обновлён. В PowerShell переменные задаются через
`$env:ИМЯ='значение'`. Runner использует `_state/typography-refresh/base.html` и
локальный Pages-артефакт `_state/typography-refresh/site-final`; при запуске он
автоматически сохранит base HTML из локального `main` и соберёт snapshot,
если этих файлов ещё нет. Для повторения именно этого отчёта база — `4b7812a`.
При необходимости `PAGES_SITE_ROOT` задаёт другой, уже собранный артефакт.
`PLAYWRIGHT_MODULE` и `CHROMIUM_EXECUTABLE_PATH` поддерживаются, как и в старых
тестах. `TYPOGRAPHY_DIR` направляет временные PNG/JSON в другое место, чтобы не
перезаписывать сохранённую съёмку. Сравнение C запускается из репозитория, где
есть `docs/typography-refresh/trial/`, а не из опубликованного артефакта.

## 7. Офлайн и PWA

После сбоя CI уточнён тестовый сетевой режим: Playwright 1.48.2 неполно отключал
сеть SW, поэтому прежняя эмуляция могла получать HTML с живого сервера.
Теперь тест дополнительно отключает сам origin и проверяет холодный worker.
[Причина, диагностика и исправление](sw-offline-investigation.md).

SW обновлён с `sudak-matches-v14` на `sudak-typography-v15`: добавлены precache и
cache-first для трёх шрифтов. Политика данных и остальные правила fetch сохранены.
Старый визуальный установщик лишь распознаёт новую версию, его идемпотентность
сохранена. Manifest и иконки не менялись.

[Отдельный настоящий офлайн-тест](offline.json): установлен v14, выполнено
обновление до v15, проверено удаление старого кэша и наличие трёх WOFF2. Затем
документ закрыт, сеть отключена, HTTP-кэш отключён через CDP. В новых документах
открыты и перезагружены прямые URL главной, чемпионата, клуба, профиля и матча
в обеих темах. Реальный отрисованный шрифт проверен через CDP: IBM Plex Sans,
а не системная подстановка. Отдельно искусственно недоступные WOFF2 проверяют
настоящий системный fallback и отсутствие горизонтальной прокрутки. Возврат сети
восстанавливает сетевые данные. Сборка Pages выполнена локально, без публикации.

## 8. Ограничения

Проверено на Chromium/Windows; отдельного прогона Safari/iOS и реальной установки
на Android не было. Штатные переносы статусов, дат и фоны эмблем оставлены для
следующей задачи; они видны в кадрах. Портрет Попова на РФФК не удалось получить:
прямой запрос официального JPEG завершился тайм-аутом 20 секунд. В воспроизводимых
парах показаны штатные инициалы, одинаковые до/после; фотография не подменялась.
Особенности полноты и давности футбольных данных остаются ограничениями источника.

Публикация сайта и объединение PR не выполнялись.
