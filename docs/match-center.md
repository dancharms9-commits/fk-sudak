# Центр матча ФК «Судак»

Работа начата от `main` (`7090b8f`) после проверки слияния PR #15 (`66f4f4c`).
Ветка: `feat/match-center`. Архитектура, идентификаторы и hash-маршруты сохранены.

## Аудит и источник

Матчи связываются ключом `2026|дата|соперник|дома/в гостях`. Результаты остаются
в `res`, будущие игры — в `next`, протоколы — в `match_details`. В профилях голы
связывались только по точному имени или однозначным фамилии и инициалам; автоголы
не входят в личные голы. Офлайн используется прежний localStorage `sudak-data-v1`
и оболочка SW. History state хранит фильтр, прокрутку и фокус ссылки.

Проверен полный официальный протокол [38762](https://rffk-roo.ru/matches/38762/).
В источнике есть стартовые составы, запасные, номера части игроков, карточки и
отдельные события выхода/ухода с поля. Их прежний загрузчик пропускал. Легенда
источника и его CSS подтверждают значения icon_1…icon_10. Сохранена реальная
сокращённая HTML-фикстура без скриптов, логотипов и постороннего содержимого.

`parse_match_protocol` дополнен необязательными `events`, `events_complete`,
`lineups`, `competition`, `round`. Используются те же запросы протоколов из
существующего почасового обновления. Новых запросов из приложения и отдельной
базы нет. Информация принимается после прежней проверки турнира, сезона, даты,
команд, счёта и полной последовательности голов. Неизвестные события не
угадываются; неполнота отмечается. Отсутствующий состав не превращается в пустую
подтверждённую заявку. Тренеры и представители не попадают в список игроков.

В существующие 16 протоколов добавлены поля из соответствующих официальных
страниц: 473 события и составы обеих команд. Все прежние поля каждого протокола,
результаты, календарь, таблица, новости, состав клуба и статистика 41 игрока
проверены на неизменность. Обновлена только дата версии набора данных.

## Экран

- Шапка: турнир, известный тур, статус, команды, утверждённая эмблема Судака,
  нейтральная заглушка соперника, центральный итоговый счёт, дата/время/стадион.
- Компактная сводка выводит доступные поля. Будущая игра не получает счёт 0:0;
  отсутствие времени или стадиона не создаёт ряда прочерков. Отмена и перенос
  отображаются только при явном `match_status` в согласованных данных.
- Каждый подтверждённый гол остаётся отдельной записью с типом. Для автогола
  различаются команда автора и команда, в пользу которой изменён счёт.
- Вертикальная хронология включает только события источника. Замены не
  объединяются в выдуманные пары. Без минут показан список в порядке источника;
  при наличии только голов это явно подписано. Пустая хронология скрывается.
- Составы разделены на стартовых и запасных по заголовкам источника. Запасные
  раскрываются обычным доступным `details`. Неизвестные номера и позиции не
  подставляются. Составы без данных скрываются; схемы поля нет.
- Полный протокол открывается по прежней официальной ссылке в новой вкладке.
  Отдельный дублирующий экран не создаётся. Расширенной статистики в источнике
  нет: блок ударов, владения и других отсутствующих показателей скрыт.

Матч открывается из будущих и завершённых игр календаря, обеих карточек главной
и списка голов в профиле. Имена связываются только с существующими профилями
Судака. Проверяются команда, полное имя и официальный ID заявки; без заявки —
прежнее осторожное сопоставление по всему клубному составу. Неоднозначное имя
остаётся текстом. Соперники не получают новые профили. Личная статистика не
пересчитывается по карточкам или автоголам.

Возврат поддерживает `матч → профиль → гол → профиль → исходный матч`, включая
прямые ссылки и перезагрузку. Сохраняются исходная вкладка, фильтр, точное событие,
фокус, прокрутка и раскрытые запасные. Новая версия данных обновляет открытый
матч без смены маршрута; неизменившаяся разметка не заменяется.

CSS из `match-center.css` встроен в HTML, поэтому оформление входит в прежнюю
офлайн-оболочку. Стили ограничены `#match`; главная из PR #15 не переработана.
Смартфоны: один столбец, центральный счёт, переносы названий и safe-area. От 768 px
допускаются две колонки. Появление — 200 мс, отклик ссылок — 180 мс; reduced motion
учитывается, постоянных анимаций нет. SW обновлён с v8 до `sudak-match-v9`.
Manifest, PNG, контроллер и время заставки 3500 мс не менялись.

## Проверки

```sh
python -m unittest discover -s tests -v
node --test tests/*.test.cjs
node tests/browser.cjs
node tests/home-dashboard.browser.cjs
node tests/match-center.browser.cjs
node tests/launch-splash.browser.cjs
git diff --check
```

Новые тесты проверяют реальную разметку РФФК, составы и номера, типы и порядок
событий, голы/пенальти/автоголы/однофамильцев, старые и неполные данные,
отсутствующие время/стадион/заявки/хронологию/статистику, все 16 источников,
переходы и возврат, обновление открытого матча, фокус и раскрытые списки.
Браузерная матрица: 320/390/768/1440 × обе темы × motion/reduce. Проверяются
переполнение, нижнее меню и ошибки JavaScript. Снимки сохраняются в CI.

Настоящий SW проверяется на подкаталоге `/fk-sudak/`: обновление v8 → v9,
офлайн-перезагрузка сохранённого матча с событиями и составами, переход к профилю,
понятное состояние без сохранённых протоколов и восстановление сети без
повторной заставки. Существующие наборы продолжают проверять главную, все 41
профиль, таблицу, новости, фильтры, прокрутку и байты утверждённых иконок.

Внешняя страница полного протокола требует сети. Внутри PWA сохранённые данные
доступны офлайн; старый кэш без дополнений показывает прежние подтверждённые голы.
Физическая установка WebAPK и системная заставка Android не проверялись.
